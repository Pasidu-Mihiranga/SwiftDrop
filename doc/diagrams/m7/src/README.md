# M7 diagram sources

The M7 figures (`../*.svg`, `../*.png`) and `doc/m7-design.pdf` are generated by the Python scripts in this folder.
Edit the scripts, never the SVG files. The drawing primitives, the geometry checker and the page skeleton are shared
with `doc/diagrams/m10/src`, so nothing is duplicated here.

| Script | Figures |
|---|---|
| `fig_usecases.py` | 01 use cases |
| `fig_er.py` | 02 data model |
| `fig_architecture.py` | 03 architecture |
| `fig_integration.py` | 04 integration patterns 1-10 |
| `fig_flows.py` | 05-09 sequences, 11 state diagram, 12-13 class diagrams |
| `fig_activity.py` | 10 order request activity |
| `build_figures.py` | the figure registry, titles and captions |
| `m7_page.py` | the text of the design document |
| `render.py` | runs the check, writes the PNGs, SVGs and PDF |

## Rebuild

Needs Python 3.9+, Pillow, `websocket-client` and Google Chrome (the path is at the top of `render.py`).

```bash
python doc/diagrams/m7/src/render.py
```

The geometry check catches crossing, overlapping and clipped shapes, but not text that wraps badly, so look at every
PNG you change.
